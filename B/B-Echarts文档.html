    },

        min: 0,// 最小值

        max:100,// 最大值
        type: 'value'
    },
    series: [{
        name:'XXX1',
        data: YData,// y轴坐标
        type: 'line'
    }]

  • grid配置如下：

    • show：是否显示直角坐标系网格
    • left：组件离容器左侧的距离可以是百分比、具体的像素、也可以是left/right/center;
    • right：同left解释
    • top：组件离容器上侧的距离。
    • bottom：组件离容器下侧的距离。

  • series配置

    • name：系列名称，用于tooltip的显示，legend 的图例筛选
    • data:数据
    • type：组件类型，bar表示柱状图、line表示折线图、pie表示饼状图、radar表示雷达图、scatter表示散点图等。

MUI部分配置

（1）时间选择器

  • 引入CSS

    xxxxxxxxxx
    <link href="../css/mui.min.css" rel="stylesheet" />
    <link rel="stylesheet" href="../css/mui.picker.min.css">

  • 创建元素并实现逻辑

    xxxxxxxxxx
    <body>
        <p id='time-info' class="btnmui-btnnui-btn-block">请选择时间</p>
        <script src="../js/mui.min.js"></script>
        <script src="../js/mui.picker.min.js"></script>
        <script type="text/javascript">
            mui.init();
            document.getElementById("time-info").addEventListener("tap",function(){
                let picker = new mui.DtPicker({
                    "type":"datetime"
                });
                picker.show(function(item){
                    document.getElementById("time-info").innerHTML = item.text+":00"
                })
            })
        </script>
    </body>

说明：

  • type：datetime/date/time

    注意： datetime只能选取到分钟
